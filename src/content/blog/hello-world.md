## 为什么要有这个博客

信息流刷得越多，记住的越少。写下来就不一样：为了让别人看懂，你必须先把事情想清楚。

所以这里的定位很简单：

- 记录解决过的技术问题，免得下次再踩一遍
- 写清楚一件事的来龙去脉，而不是只贴结论
- 偶尔写点与代码无关的东西

## 这个站点是怎么搭的

技术选型刻意保持简单：

| 环节 | 选择 | 理由 |
| --- | --- | --- |
| 框架 | Astro | 默认零 JS，内容站首选 |
| 内容 | Markdown | 纯文本，永不被平台绑架 |
| 托管 | EdgeOne Pages | 国内访问快，有免费额度 |
| 评论 | Giscus / 自建 KV | 静态站也能有互动 |

整体是**静态输出**：构建时把所有页面生成成 HTML，访问时直接由 CDN 返回，没有服务器需要维护。

> 静态不代表不能有互动。评论、访问统计这类需求，都可以通过第三方服务或边缘函数补上。

## 怎么写一篇新文章

在 `src/content/blog/` 下新建一个 `.md` 文件即可：

```markdown
---
title: 文章标题
description: 一句话摘要，会显示在列表和搜索结果里
pubDate: 2026-02-01
tags: ['标签一', '标签二']
---

正文从这里开始……
```

文件的**文件名就是网址**。比如 `hello-world.md` 对应 `/blog/hello-world/`。

## 关于代码块

行内代码写作 `` `const x = 1` ``，代码块用三个反引号并标注语言，会自带语法高亮：

```js
// 支持明暗两套主题，跟随站点自动切换
export function greet(name) {
  return `你好，${name}！`;
}

console.log(greet('世界'));
```

```bash
# 本地预览
npm run dev

# 构建静态站点
npm run build
```
